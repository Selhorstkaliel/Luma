Luma-OS - ISO PRÉ-ALPHA (somente para máquina virtual)

ATENÇÃO: USE SOMENTE EM MÁQUINA VIRTUAL, COM UM DISCO VIRTUAL VAZIO.
Até o run iso #10 a ISO instalava sozinha e apagava o disco sem perguntar. Desde a Fase 6 o
instalador deve parar na tela "Resumo da instalação" e esperar você escolher disco e usuário;
o teste de boot do CI agora reprova se a instalação começar sem interação (veja boot/boot-resultado.txt).
Mesmo assim: confira a tela de resumo antes de clicar em instalar e nunca dê boot com esta ISO
em um computador real, nem com pendrive esquecido na porta USB.

Esta ISO é um build automático de desenvolvimento, sem garantia de nenhum tipo.
O que ela contém: Fedora Kinoite 44 com a identidade Luma, firewall de entrada fechado,
tema Luma Midnight, tela de boot Luma, app Ajustes, "luma-jogos" (Steam/Lutris/Heroic/Bottles via
Flathub) e o comando "sudo luma-diagnostico". Recuperação: docs/usuario/recuperacao.md no repositório.

Conferir o arquivo antes de usar:
  sha256sum -c luma-*-x86_64.iso.sha256

Testar em VM com Secure Boot (laboratório do projeto):
  BOOT_ISO=luma-*-x86_64.iso scripts/lab/lab.sh install

Este arquivo é apagado automaticamente do GitHub 7 dias depois do build.
Projeto: https://github.com/Selhorstkaliel/Luma (não é produto do Projeto Fedora nem endossado por ele).
